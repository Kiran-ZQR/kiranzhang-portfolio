01Overview

Shorten the path from an idea to a working interface.

I participated in selected small tools, including moon-phase and fuel-related utilities. The work included data import, UI production and layout, motion and experience refinement. Integration and launch still required team collaboration.

02The challenge

A working page is not yet a complete experience.

AI can produce a first version quickly. Requirements, input definitions, error recovery and result explanations still need deliberate decisions—and similar decisions recur across tools.

03Design approach

Make the task the unit of collaboration.

The notes record the task brief, interface constraints and acceptance feedback. Existing guides support environment setup and phased work from clarification through generation and BUILD.

  1. 01

    Define the task and constraints

  2. 02

    Generate and refine the interface

  3. 03

    Check states and write back feedback

04The experience

Make fuel consumption understandable and checkable.

Distance and fuel consumed must cover the same interval. Show the result in litres per 100 km, retain the inputs, and expose the calculation rather than assigning an unsupported high/low label.

INTERACTIVE DESIGN EXAMPLE

Calculate fuel consumption

Use distance and fuel consumed over the same interval. Example: distance between two full-tank fills, with the fuel added at the second fill.

Example result

7.50L / 100 km

31.5 ÷ 420 × 100 = 7.50

Based on 420 km travelled and 31.5 L consumed

05Outcome

Keep the outputs distinct from the next hypotheses.

The work leaves tool interfaces, collaboration documents and concrete task rules. News-context value, independent usability and collaboration savings remain questions for the next round of testing.
