One identity. A continuous experience.

Connecting owner profiles, visitor profiles and immersive video controls across the WeChat plugin and Tencent News app.

IN THIS CASE

OverviewThe challengeDesign approachThe experienceOutcome
01Overview

A plugin people return to.

The plugin supports more than opening an article. Users need to recognise a creator, follow them, return to their own profile and manage saved content. Those tasks should remain connected when moving between WeChat and the app.

02The challenge

The journey was split in three places.

Reviewing the current flow exposed spatial, identity and state discontinuities.

01

Limited space

Bottom half-screen tools compete with the video for vertical space.

02

Inconsistent profiles

The same person is represented differently across plugin and app.

03

Incomplete follow-up

A cross-surface jump can leave the user without a clear return or confirmation.

03Design approach

Use continuity as the organising principle.

The direction connects the immersive feed, a side drawer, owner/visitor profiles and app destinations. Tools need their own space; profile structure and user state need a shared logic.

  1. 01

    Watch content

  2. 02

    Open tools or a profile

  3. 03

    Act and return in context

04The experience

Keep content playing while actions happen alongside.

A side drawer frees controls from the video’s vertical space. A consistent profile destination helps users move from discovering another person to managing their own relationships and content.

05Outcome

A connected profile and tool structure.

The delivery connects profile entry, personal content and immersive controls. Its main design contribution is a shared interaction structure: people can recognise where they are, act on the same identity, and continue across surfaces.
