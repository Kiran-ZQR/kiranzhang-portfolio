# 完整织机与独立轮盘 / 当前版本

用户修订后的体验，不再是两处机架特写。

- 桌面左 80% 是水平 40° 视角的完整织机；右 20% 仅显示同源轮盘几何，不含机架。右侧副本与真实手柄共享旋转状态和原有几何/材质，没有独立创作状态。手机上下排列，轮盘镜头单独适配完整手柄的尺寸。
- weave-opening.js 提供全屏 Canvas 开场。横纵纱线从屏幕边缘进入，沿字形的经纬区间收束成标题，再退出至模型页面。支持跳过、Escape、减少动态效果；播放时背景界面 inert，焦点留在跳过按钮。
- 拖动时布面逐段显示种子，不演化。松手之后用原 B3/S23 运行 18 代（每代 180ms），期间暂不接受新的转动；结束后可续织或完成。键盘/四分之一圈按钮在连续输入停止 450ms 后开始演化。核心规则未修改。
- 历史布段和演化后的网格快照保存在 v4 本地会话中，刷新重建结果一致。返回首页入口位于顶部和结果页，目标 index.html#home；返回织机不清空。
- 旧脚本和原模型均保留。新增开场文件，修改 weave-experience.js/css 与 life-weave.html 的脚本引用；未修改主作品集首页。

验证：`node .preview/test-weave-v4.cjs`，检查全屏开场、真实鼠标拖动、拖动期间零代演化、松手后18代、播放期间控件锁定、保存恢复后的 PNG 一致性、首页链接和手机无横向溢出。旧 v2 测试的“整圈立即演化一代”断言不再适用。
